# 画屿 · 本地插画图库

一个在自己电脑上运行的插画图库。前端样式和脚本已合并在单个 `index.html` 中；Pixiv 账号连接和原图保存由本地 `server.py` 提供。可查看关注画师的新作、个性化推荐和全站排行榜，选择作品保存所有原图；也可导入已有图片，按画师、标签、标题或 ID 查找。图片和数据库只保存在本机的 `data` 文件夹。

## 启动

下载 Windows 版 `pixiv-gallery.exe` 后，放到你想存放图库的文件夹，双击即可打开画屿独立窗口；**无需安装 Python，不再弹出命令窗口**。关闭画屿窗口时，本地服务一起停止。图片、数据库和加密保存的会话都在 EXE 同文件夹的 `data` 目录。升级时先关闭旧版，再把新版 EXE 放回原文件夹，保留 `data` 目录即可。如果使用同目录的“画屿.exe”入口，也应替换该 EXE；两个入口共用同一图库。Windows 偶尔缓存旧文件名的图标，可使用“画屿.exe”文件名重新读取图标。

桌面版使用 Microsoft Edge WebView2。若启动时提示缺少运行时，可从 [Microsoft 官方页面](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)安装 Evergreen WebView2 Runtime。重复双击程序会尝试激活已打开的画屿窗口。桌面版自动使用可用的本地端口，不依赖固定的 8765 端口。

如果使用源码或代码压缩包，则需要 Python 3.10 或更新版本。Windows 上双击 `start.bat` 可打开浏览器版，无需第三方 Python 包。运行桌面版源码需先安装 `requirements-desktop.txt`，再执行 `python desktop.py`。

浏览器版如果提示 **Failed to fetch**，通常是直接双击了 `index.html`，或本地服务没有运行。请运行 `start.bat`，等命令窗口显示服务地址，再通过 <http://127.0.0.1:8765> 打开。桌面 EXE 应直接打开独立窗口；若无法启动，请查看 `data/desktop-error.log`。不要把 Cookie 发给别人。

如果搜索时提示“旧版本地服务”或“本地服务返回了无效数据”，请关闭**所有**已打开的画屿命令窗口，再运行当前文件夹中的新版 EXE 或 `start.bat`，然后刷新网页。旧版服务可能仍占用 `8765` 端口；新版会阻止多个服务同时监听同一端口。

也可以在本文件所在文件夹打开 PowerShell，运行：

```powershell
python server.py
```

浏览器打开 <http://127.0.0.1:8765>。按 Ctrl+C 停止服务。**请通过这个地址打开网页，不要双击 `index.html`**；浏览器的安全限制使单个本地 HTML 无法直接访问 Pixiv 账号接口并保存原图。

## 使用

1. 点击“添加插画”，可上传已保存的图片。导入后点击作品卡片填写画师和标签；若知道对应的 Pixiv 链接，也可在详情中点击“读取标签”，再保存。标签可连续输入 `#tttt #yyy`：输入第二个 `#`（也支持全角 `＃`）时，前一个标签会变成气泡；按回车或保存可完成最后一个标签，点击气泡上的 × 可移除。
2. 切换到“从 Pixiv 导入”，粘贴类似 `https://www.pixiv.net/artworks/12345678` 的链接或数字 ID。程序会获取该作品所有图片页的原图、标题、画师和标签。
3. 点击画师或标签进行筛选，或用顶部搜索框检索。单击图库卡片可查看详情；双击卡片会用系统默认图片程序打开本地原图，并在资源管理器中定位该文件。详情页中的图片也可双击打开当前页，或使用“打开本地原图”“在文件夹中显示”按钮。详情中的“查看相关 Pixiv 作品”可点击画师查看其其他插画、点击标签搜索同标签作品；也可以修改标签、下载当前原图、打开 Pixiv 来源页。
4. 点击右上角“连接 Pixiv”，输入自己账号的 `PHPSESSID` Cookie 值。连接后进入“关注新作”或“发现推荐”，点击作品图片打开预览；预览中的画师名称可查看其其他插画，标签可直接搜索，返回按钮可回到之前的页面。也可选择“保存原图到图库”。保存后的文件在 `data/images/`。
5. 网页打开期间，每 5 分钟检查一次关注新作；检测到新作品会显示页内提示和侧栏数字。关闭网页或本地服务后不会继续检查。
6. 点击侧栏“搜索 Pixiv”，选“插画作品”可按标签或关键词搜索；选“画师”可输入画师名称、用户 ID 或画师主页链接。点画师的“查看作品”进入其作品列表，再点作品预览或“保存原图到图库”。插画搜索可查看公开内容；按画师名称搜索需要先连接 Pixiv 账号，输入用户 ID 或主页链接可直接查看公开资料。搜索结果可翻页，保存后原图和 Pixiv 标签会进入本地图库。
7. 点击侧栏“已关注画师”，浏览当前 Pixiv 账号公开及私密关注的画师；点击“查看作品”可浏览该画师插画并选择保存原图。返回画师列表时会恢复原页码和滚动位置，已看过的列表页会在当前网页会话中缓存；点击“刷新列表”可重新获取。此功能需要连接 Pixiv 账号。
8. 在“搜索 Pixiv → 插画作品”中输入指定标签，排序可选“最新”“热门精选”或“完整热门排序”。热门精选取自 Pixiv 返回的少量热门作品，通常不足一页；完整热门排序是 Pixiv Premium 功能。非 Premium 账号选择完整热门排序时，程序会明确提示，不会把最新顺序误称为热门顺序。
9. 每次从侧栏进入“发现推荐”都会重新向 Pixiv 获取作品；允许再次看到以前推荐过或已保存的作品。从作品预览返回时保留当前列表，向下滚动时继续自动获取。只对当前列表内的作品去重；若 Pixiv 这一批只返回当前列表已有的作品，会在底部稍后重试。刷新表示重新请求，并不保证 Pixiv 每次返回不同内容。
10. “全站排行榜”提供 Pixiv 插画日榜、周榜、月榜和新人榜，可翻页查看并保存原图。
11. 在“搜索 Pixiv → 画师”的结果卡片、画师作品页，或作品预览里点击“关注画师”，会使用当前连接的账号尝试同步关注到 Pixiv。作品预览可先选择“公开”或“私密”；其他位置默认公开。程序会从当前登录的 Pixiv 页面读取认证令牌，提交后再确认关注状态；成功后“已关注画师”列表缓存会更新。若 Pixiv 拒绝程序请求，页面会显示“打开画师主页并关注”链接；在 Pixiv 原站点击关注，返回画屿后会自动检查并同步状态。网页关注的公开/私密设置以 Pixiv 页面上的选择为准。
12. 在本地图库点“批量编辑”，选择作品或“全选当前结果”，再点“修改画师 / 标签”。可以统一填写画师名称与 Pixiv 画师 ID，也可以用同样的 `#` 分隔输入方式对标签执行添加、移除或替换。批量修改只更新本地图库的元数据，不会修改 Pixiv 上的作品或文件本身；一次最多处理 500 件作品。

13. 点击右上角“外观”，可自定义主题色、背景色，选择本地图片作为壁纸并调节遮罩。提供暮色紫、海岛绿、暖纸白三种预设，深浅背景会自动调整文字颜色。修改即时预览，点击“保存外观”后持久保存；直接关闭设置会取消未保存的预览。“移除壁纸”和“恢复默认”也需要保存后生效。壁纸支持 JPG、PNG、GIF、WebP、AVIF，最大 20 MB，复制保存在图库的 `data/appearance/` 中，原文件移动不影响已保存的壁纸。

14. 在 Pixiv 作品预览或列表中，已保存作品会显示“在图库中找到插图”。点击后定位本地图库中的对应作品，打开第一张本地原图，并在资源管理器中选中它所在文件夹中的文件。新保存的作品也会立即变为这个按钮，不会重复下载。
15. 点击顶部 ←、按 `U` 或鼠标后退侧键可返回上一页或关闭当前预览；恢复之前的列表、筛选、页码和滚动位置。浏览器后退/前进与桌面 WebView 使用同一份页面历史，预览里的画师和标签支持多层回退。从推荐返回时保留原列表；再次从侧栏进入推荐仍重新刷新。

### 快捷键

导航按键沿用 [Discourse 的快捷键定义](https://github.com/discourse/discourse/blob/main/frontend/discourse/app/services/keyboard-shortcuts.js)，对应到图库中的操作：

| 按键 | 操作 |
| --- | --- |
| `U`、鼠标后退侧键、`Alt + ←` | 返回上一页或关闭当前预览 |
| `/` | 聚焦本地或 Pixiv 搜索 |
| `J` / `K` | 选择下一件 / 上一件作品或画师 |
| `O` / `Enter` | 打开选中的预览或画师作品 |
| `G` 再 `H` | 回到全部插画 |
| `?` | 显示快捷键帮助 |
| `Esc` | 关闭当前弹窗 |

单字母快捷键在输入框、标签编辑器、下拉框和中文输入过程中不触发。页面历史和浏览列表在本次窗口会话中保留，重新打开窗口后重新建立。

### Pixiv 登录 Cookie

部分公开作品可以直接导入。关注新作和个性化推荐需要登录状态。可在浏览器开发者工具的“应用程序/存储 → Cookies → pixiv.net”中找到已登录账号的 `PHPSESSID`，然后在页面右上角输入其**值**。默认勾选“在这台电脑记住连接”：程序会使用 Windows 当前用户的加密功能，把会话保存在 `data/pixiv_session.bin`，下次启动自动读取。取消勾选则只在本次运行期间使用。点击“断开连接”会清除内存中的会话及保存文件。**不要把 Cookie 发给别人，也不要把它写入项目文件或截图公开。**

如果不想在页面输入，也可以在启动服务的同一个 PowerShell 窗口运行：

```powershell
$env:PIXIV_PHPSESSID = Read-Host "输入自己的 Pixiv PHPSESSID"
python server.py
```

关闭此 PowerShell 窗口后，临时环境变量便不再保留。加密保存不会延长 Pixiv 会话本身的有效期；如果 Pixiv 使其失效，需要重新复制一次 Cookie。Pixiv 没有公布可保证的固定有效天数。

## 源码测试与打包

本地服务与以下模拟测试只使用 Python 标准库。命令需要在完整的源码仓库中运行；模拟测试不需要 Pixiv 账号，也不会向 Pixiv 发送关注请求：

```powershell
python tests/test_follow_bulk.py
python tests/test_discovery.py
python tests/test_appearance.py
python tests/test_local_open.py
```

生成与 Release 相同的代码下载包：

```powershell
python scripts/package_release.py v0.5.0
```

在 Windows 源码仓库中安装 PyInstaller 后，可生成单文件 EXE：

```powershell
python -m pip install -r requirements-build.txt
python scripts/build_exe.py
python scripts/smoke_exe.py
```

代码下载包包含网页、本地服务、桌面入口、应用图标、桌面依赖说明、浏览器版启动器和使用说明；EXE 内嵌网页、图标、本地服务及桌面窗口依赖。两种包都不会包含 `data/` 中的 Cookie、数据库、壁纸或图片。

## 数据与限制

- `data/library.sqlite3` 保存标题、画师、标签和图片文件名；`data/images/` 保存原图。`data/appearance.json` 保存外观设置，`data/appearance/` 保存壁纸，浏览器版与桌面版共用。桌面窗口的浏览器缓存保存在 `data/webview/`。备份时复制整个 `data` 文件夹。加密会话文件通常只能由同一台电脑的同一 Windows 用户解密；移到另一台电脑后需重新连接 Pixiv。
- Pixiv 导入、关注动态和发现推荐使用其网页内部接口，并非官方对第三方开放的稳定 API。Pixiv 改动接口、登录方式或访问策略时，这些功能可能失效。动图暂不支持。
- Pixiv 可能要求浏览器完成关注验证，仅用 Cookie 和认证令牌发送请求仍会被拒绝。程序会显示 Pixiv 画师主页入口，并在你从 Pixiv 返回后检查实际关注状态；不会把未确认的请求显示为“已关注”。[Pixiv 官方帮助](https://www.pixiv.help/hc/en-us/articles/235596967-What-is-following)说明公开关注可被他人看到，私密关注不会公开显示。
- [Pixiv 官方帮助](https://www.pixiv.help/hc/zh-cn/articles/34189864850073-%E4%BB%80%E4%B9%88%E6%98%AF%E5%8F%91%E7%8E%B0%E5%88%86%E9%A1%B5)说明，发现页会参考浏览记录、热门标签等。程序直接使用 Pixiv 的发现结果和顺序，不自行推断其内部推荐算法。该接口没有稳定的翻页游标，连续请求可能重复；程序每次进入都会刷新，但不能保证 Pixiv 每次提供不同作品。
- Pixiv 的完整热门排序需要 Premium 账号；热门精选的数量由 Pixiv 返回，不能按页浏览全部作品。
- 每次只导入一件作品，单张图片上限 60 MB。图库默认只监听 `127.0.0.1`，请勿将服务直接暴露到公网。
- 请按 pixiv 规则及画师授权使用图片；公开展示、转载或分享原图前，应取得相应许可。
